# Misses checklist

Problems a review missed that became rules. An item lands here only after it showed up in two or more reviews and a diff can show it. The review runs only the items whose trigger matches the diff, and names each one that fired in its report. An item no report has named in two months is dropped the next time an item is added.

Each item is one line: `- **<trigger>** · <the check> · added <YYYY-MM-DD> from <reviews>`
