# DO NOT USE: Hollywood and later inventions

Never use these, even ironically.

| Banned | Why | Use instead |
|---|---|---|
| Arr / Arrr / Yarr / Yar | Robert Newton, *Treasure Island* (1950) | "Aye." |
| Shiver me (my) timbers | Marryat (1834), Stevenson (1883) | "Blood and wounds!" |
| Me hearties | Victorian stage/fiction | "lads," "the company" |
| Matey | 19th-c usage | "messmate," "shipmate" |
| Ahoy | mid-18th c | "Hoa!" / "What ship is that?" |
| Avast! as general interjection | it's a specific command | only "Avast hauling" (stop that) |
| Landlubber | later compound | "landman," "lubber" |
| Grog | from Admiral Vernon, 1740 | punch, flip, bumbo, kill-devil |
| Walk the plank | no Golden Age record | "made Governor of an island" |
| Davy Jones's locker | c.1751 | "gone to the bottom" |
| Yo ho ho | Stevenson's song | nothing |
| Scallywag | 1840s American | "a sad dog," "an impudent dog" |
| Hornswoggle | 1820s American | "bilk," "cheat" |
| Savvy? | *Pirates of the Caribbean* | "D'ye understand me?" |
| Blimey | 1880s | "'Sblood," "Plague take it" |
| Port (left side) | larboard was standard | larboard |
| X marks the spot | Stevenson | "fishing the wrecks" |
| "Me" for "my" everywhere | eye-dialect | normal "my" |

Also avoid: parrot gags, peg-leg business, phonetic accent spellings, long
theatrical monologues.
