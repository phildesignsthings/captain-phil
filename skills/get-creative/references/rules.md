# The rule spent — d6, the generic table

The fourth die. One rule the surface lives by, broken on purpose, so that restraint can win and
a break costs something real. Entry 1 is fixed in every round. Entries 2 to 6 come from the
surface's `DESIGN.md` § Named Rules when the record exists: `scripts/roll.mjs` takes the bold
lead of the first five bullets there. Without a record it takes the five below and says so.

1. Nothing — fully inside the rules
2. One accent colour per screen
3. The type scale is the only source of size
4. Every corner shares one radius
5. Content sits on the column grid
6. One figure per screen
